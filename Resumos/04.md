# Resumo de Aula: Ethernet, MAC Address e ARP

## 1. Introdução

A comunicação dentro de uma rede local (LAN) depende da integração entre três conceitos fundamentais da Camada 2 (Enlace): o padrão de cabeamento e transmissão **Ethernet**, a identificação física única via **MAC Address** e o protocolo de tradução **ARP**. Juntos, eles garantem que os dados trafeguem do hardware de origem até o hardware de destino correto na mesma rede.

- **Importância Prática:** Entender esses três elementos é essencial para analisar quadros de rede no Wireshark, diagnosticar falhas de conectividade local e compreender ataques de segurança como _ARP Spoofing_ e _MAC Flooding_.

---

## 2. Conceitos Chave

- **Ethernet (Padrão de Rede Local):**
  - **O que é:** O padrão de tecnologia de rede mais utilizado para conectar dispositivos em uma rede local (com fio 802.3 ou sem fio/Wi-Fi 802.11).
  - **Função:** Define como as placas de rede formatam os dados em **quadros (_frames_)** e como o sinal elétrico ou óptico é transmitido pelo meio.
  - **Estrutura do Quadro Ethernet:** Contém o MAC de Origem, MAC de Destino, Tipo de Protocolo (ex: IP ou ARP) e os Dados (_Payload_).

- **MAC Address (Endereço Físico):**
  - **O que é:** Um identificador de 48 bits (12 caracteres hexadecimais, ex: `00:1A:2B:3C:4D:5E`) gravado diretamente na memória ROM do chip da placa de rede.
  - **Estrutura:**
    - **Primeiros 3 bytes (OUI):** Identificam o fabricante do hardware (ex: Cisco, Intel, Realtek).
    - **Últimos 3 bytes (NIC):** Número de série único atribuído pela fabricante.
  - **Escopo:** Funciona **apenas dentro da rede local**. O endereço MAC nunca atravessa um roteador para a Internet.

- **ARP - Address Resolution Protocol (Tradutor de Rede):**
  - **O que é:** O protocolo responsável por mapear e traduzir um **Endereço IP (L3 - Lógico)** em um **Endereço MAC (L2 - Físico)**.
  - **Funcionamento:**
    1. **ARP Request (Broadcast):** O host pergunta para toda a rede _"Quem tem o IP `192.168.1.10`? Responda para o meu MAC"_.
    2. **ARP Reply (Unicast):** O dono do IP responde diretamente _"Eu sou o IP `192.168.1.10` e meu MAC é `AA:BB:CC:DD:EE:FF`"_.
  - **Tabela ARP (Cache):** Memória temporária no sistema operacional que armazena os pares IP-MAC recentemente descobertos para evitar requisições repetidas.

---

## 3. Comandos Práticos no Terminal

Para visualizar e gerenciar a tabela ARP no sistema operacional:

- **Exibir a Tabela ARP:**
  - **Windows:** `arp -a`
  - **Linux / Mac:** `arp -n` ou `ip neigh`
- **Limpar/Resetar a Tabela ARP:**
  - **Windows:** `netsh interface ip delete arpcache` (Prompt em modo Administrador)
  - **Linux:** `ip neighbor flush all`

## 4. Analogia da Convivência no Prédio

Para entender a relação entre Ethernet, MAC e ARP no dia a dia:

1. **Ethernet (A Infraestrutura do Condomínio):** É o conjunto de corredores, elevadores e interfones que conectam os apartamentos.
2. **MAC Address (A Identidade Física/RG):** É a foto e o documento de identidade de cada morador. Cada pessoa tem o seu RG único impresso de fábrica.
3. **Endereço IP (O Número do Apartamento):** É o número dinâmico e lógico de onde a pessoa mora temporariamente (ex: Ap 102).
4. **ARP (O Interfone da Portaria):** Quando a portaria precisa entregar uma encomenda para o morador do Ap 102 (IP), ela usa o interfone e pergunta: _"Quem é o morador do Ap 102?"_. O morador atende, confirma o seu RG (MAC) e a portaria entrega a encomenda diretamente em mãos.
