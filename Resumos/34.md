# 🐧 ip e ss — Diagnóstico de Rede no Linux

> **Definição Simples:** Os comandos **`ip`** e **`ss`** são as ferramentas modernas essenciais do ecossistema Linux (pacote `iproute2`) para gerenciar e diagnosticar a rede. Eles substituem com vantagem e maior velocidade os utilitários legados e obsoletos **`ifconfig`** e **`netstat`**.

---

## 🌐 1. Comando `ip` (Gerenciamento de Interfaces e Rotas)

O comando `ip` manipula placas de rede, endereços IP e tabelas de roteamento.

- **Ver interfaces de rede e endereços IP:**
  ```bash
  ip addr show
  # Ou a versão resumida: ip a
  ```
- **Ver a Tabela de Roteamento (Gateway Padrão):**
  ```bash
  ip route show
  # Ou a versão resumida: ip r
  ```
- **Ativar ou desativar uma interface de rede:**
  ```bash
  sudo ip link set eth0 up
  sudo ip link set eth0 down
  ```
- **Ver tabela ARP / Vizinhos da rede local:**
  ```bash
  ip neigh show
  ```

---

## 📊 2. Comando `ss` (Socket Statistics)

O comando `ss` investiga as conexões ativas e portas abertas no sistema diretamente do kernel do Linux, de forma muito mais rápida que o antigo `netstat`.

- **Listar todas as portas em escuta (Listening) e numéricas:**
  ```bash
  ss -tuln
  ```

  - `-t`: Conexões TCP
  - `-u`: Conexões UDP
  - `-l`: Apenas portas em escuta (_Listening_)
  - `-n`: Exibe o número das portas e IPs (sem resolver nomes de domínio)
- **Ver qual processo/programa está usando cada porta:**
  ```bash
  sudo ss -tulnp
  ```

  - `-p`: Mostra o PID e o nome do programa.
- **Filtrar conexões estabelecidas:**
  ```bash
  ss -state established
  ```
- **Filtrar conexões por porta de destino:**
  ```bash
  ss -tuln sport = :443
  ```

## ⚔️ De/Para: Utilitários Legados vs. Modernos

| Utilitário Obsoleto (Antigo) | Utilitário Moderno (Padrão) | Função                                       |
| :--------------------------- | :-------------------------- | :------------------------------------------- |
| `ifconfig`                   | **`ip a`** / **`ip addr`**  | Visualizar e configurar endereços IP         |
| `route -n`                   | **`ip r`** / **`ip route`** | Exibir tabelas de roteamento                 |
| `arp -a`                     | **`ip neigh`**              | Ver tabela de endereços MAC locais (ARP)     |
| `netstat -tuln`              | **`ss -tuln`**              | Inspecionar portas abertas e conexões ativas |

---

## ☁️ Aplicação Prática em Cloud Security

- **Auditoria de Portas Expostas (Hardening):** Identificar portas desnecessárias abertas localmente em instâncias Linux (`ss -tulnp`) antes de fechar os acessos no Security Group.
- **Troubleshooting de Roteamento:** Verificar se as rotas da VPC estão configuradas corretamente na tabela do sistema operacional (`ip r`).
- **Identificação de Conexões Suspeitas:** Detectar conexões ativas para IPs desconhecidos/externos em casos de suspeita de infecção ou exfiltração de dados (`ss -ta`).
- **Detecção de Conflitos de Serviços:** Descobrir rapidamente se um serviço (ex: Nginx na porta 80 ou 443) falhou ao subir porque outro processo já está utilizando a mesma porta.
