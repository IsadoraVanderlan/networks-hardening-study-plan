# 🌐 Resumo de Aula: IPv4 e Endereçamento IP

O **IPv4 (Internet Protocol version 4)** é o protocolo responsável por identificar e permitir a comunicação entre dispositivos em uma rede. Pense nele como o **endereço residencial** da sua casa, mas para computadores, celulares e servidores no mundo digital! 🏠✉️

---

## 📌 1. Estrutura do Endereço IPv4

- **Formato**: Composto por **32 bits**, divididos em **4 octetos** (conjuntos de 8 bits).
- **Notação**: Representado em formato **decimal pontuado** para facilitar a leitura humana.
  - **Exemplo**: `192.168.1.1`
- **Conversão Binária**: Cada octeto varia de `00000000` (`0`) a `11111111` (`255`).
  - **Total de Endereços**: Cerca de **4,3 bilhões** de endereços possíveis no mundo.

---

## 🎯 2. Divisão do Endereço: Rede vs. Host

Todo endereço IP é dividido em duas partes principais:

- **ID de Rede (Network ID)**: Identifica o "bairro" ou a "rua" onde a rede está localizada. Todos os dispositivos na mesma rede local compartilham essa mesma parte.
- **ID de Host (Host ID)**: Identifica o "número da casa", ou seja, o dispositivo específico dentro daquela rede.

---

## 🛡️ 3. Máscara de Sub-rede (Subnet Mask)

A máscara de sub-rede serve exatamente para avisar ao sistema operacional **qual parte do IP é rede** e **qual parte é host**.

- **Exemplo Clássico**: `255.255.255.0`
  - Onde tem `255`, indica a parte de **Rede**.
  - Onde tem `0`, indica a parte de **Host**.
- **Notação CIDR (Classless Inter-Domain Routing)**: Uma forma abreviada de escrever a máscara contando os bits `1`.
  - `192.168.1.1/24` (o `/24` significa que 24 bits são dedicados à rede, equivalente a `255.255.255.0`).

---

## 🏷️ 4. As Classes de Endereços IP (Histórico / Classful)

Tradicionalmente, os endereços IP eram organizados em 5 classes:

| Classe       | Intervalo do 1º Octeto          | Máscara Padrão        | Foco de Uso                                     |
| :----------- | :------------------------------ | :-------------------- | :---------------------------------------------- |
| **Classe A** | `1.0.0.0` a `127.255.255.255`   | `255.0.0.0` (/8)      | Redes gigantescas (poucas redes, muitos hosts). |
| **Classe B** | `128.0.0.0` a `191.255.255.255` | `255.255.0.0` (/16)   | Redes de médio e grande porte.                  |
| **Classe C** | `192.0.0.0` a `223.255.255.255` | `255.255.255.0` (/24) | Redes locais pequenas/domésticas.               |
| **Classe D** | `224.0.0.0` a `239.255.255.255` | _N/A_                 | **Multicast** (transmissão de 1 para vários).   |
| **Classe E** | `240.0.0.0` a `255.255.255.255` | _N/A_                 | Reservado para uso experimental/pesquisas.      |

---

## 🏠 5. IPs Privados vs. IPs Públicos

Para economizar os endereços IPv4, o mundo divide os IPs em duas categorias:

### 🔹 IPs Privados (Uso Interno)

Usados exclusivamente dentro de redes locais (Sua casa, empresa, universidade). **Não rodam diretamente na internet pública**.

- **Faixas Reservadas**:
  - `10.0.0.0` a `10.255.255.255` (Classe A)
  - `172.16.0.0` a `172.31.255.255` (Classe B)
  - `192.168.0.0` a `192.168.255.255` (Classe C)

### 🔸 IPs Públicos (Uso Externo)

Únicos no mundo inteiro. São atribuídos ao seu roteador pelo seu provedor de internet (ISP) para navegar na web.

> 💡 **Analogia da Carta**: O **IP Privado** é o número do apartamento interno do prédio. O **IP Público** é o endereço do prédio que os correios enxergam da rua! O **NAT (Network Address Translation)** é o porteiro que traduz tudo da rede interna para a internet externa.

---

## ⚠️ 6. Endereços Especiais no IPv4

- **Endereço de Rede**: Primeiro IP do bloco (todos os bits de host zerados). Usado para identificar a rede inteira. _Não pode ser atribuído a dispositivos._
- **Endereço de Broadcast**: Último IP do bloco (todos os bits de host em 1). Envia dados para todos os dispositivos daquela rede de uma só vez. _Não pode ser atribuído a dispositivos._
- **Loopback (`127.0.0.1`)**: Teste de interface local da própria placa de rede (o famoso "nosso lar" do computador 🏠).
- **APIPA (`169.254.x.x`)**: Atribuído automaticamente pelo Windows quando o computador não consegue encontrar um servidor **DHCP** na rede.
