# dig – Diagnóstico e Investigação de DNS

💡 Analogia do Dia a Dia

Pense no dig (Domain Information Groper) como a Lista Telefônica Inteligente da Internet. Quando você pesquisa pelo nome de uma empresa (como google.com), o dig não só encontra o número de telefone exato (o endereço IP), mas também mostra quem forneceu essa informação, quanto tempo ela ficará salva na sua memória e se há outros contatos relacionados (como servidores de e-mail).

## 🛠️ Para que serve?

O dig é a ferramenta padrão para consultar servidores DNS e solucionar problemas de resolução de nomes, mapeando como o seu sistema traduz nomes de domínio em endereços IP.

## 📌 Principais Parâmetros e Tipos de Registro

A: Retorna o endereço IPv4 do domínio.

AAAA: Retorna o endereço IPv6.

MX: Consulta os servidores de e-mail (Mail Exchange) associados ao domínio.

NS: Lista os servidores autoritativos de nome (Name Server).

TXT: Exibe registros de texto (muito usados para validações como SPF, DKIM e propriedade de domínio).

+short: Limpa a resposta, exibindo apenas a informação direta (ideal para scripts).

+trace: Rastreia todo o caminho da consulta DNS, da raiz até o servidor final (ótimo para depurar onde a resolução está falhando).

## 💻 Exemplos Práticos

# Consulta básica de IP (Registro A)
dig exemplo.com

# Consultar apenas os servidores de e-mail
dig exemplo.com MX

# Exibir resposta simplificada
dig exemplo.com +short

# Rastrear a resolução de DNS do zero
dig exemplo.com +trace

# Fazer uma consulta usando um servidor DNS específico (ex: Google 8.8.8.8)
dig @8.8.8.8 exemplo.com


💡 Dica Criativa: Se um site está fora do ar apenas para você após uma alteração de hospedagem, use dig exemplo.com +trace para ver em qual etapa da cadeia o DNS ainda está desatualizado.
