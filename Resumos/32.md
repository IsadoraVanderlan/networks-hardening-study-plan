# 🦈 Wireshark — Captura e Inspeção de Pacotes

> **Definição Simples:** O **Wireshark** é a ferramenta de análise de protocolo de rede mais famosa do mundo. Ele funciona como um **"raio-X" da rede**, capturando pacotes em tempo real para inspecionar exatamente o que está trafegando entre os sistemas.

---

## 🔍 Principais Funcionalidades

- **Captura em Tempo Real:** Intercepta o tráfego que passa pela placa de rede (NIC).
- **Deep Packet Inspection (DPI):** Analisa o conteúdo detalhado de cada camada do modelo OSI (Camada de Aplicação, Transporte, Rede, Enlace).
- **Filtros de Exibição (Display Filters):** Isolam o tráfego de interesse em meio a milhares de pacotes.
- **Análise de Fluxo (Follow Stream):** Reconstrói conversas inteiras (como sessões `TCP`, `HTTP` ou `UDP`) para leitura contínua.

---

## 🎯 Filtros Essenciais para Cloud & Security

| Objetivo                              | Filtro no Wireshark                   |
| :------------------------------------ | :------------------------------------ |
| **Filtrar por IP de origem/destino**  | `ip.addr == 192.168.1.1`              |
| **Filtrar tráfego HTTP**              | `http`                                |
| **Filtrar conexões HTTPS / TLS**      | `tls` ou `ssl`                        |
| **Filtrar por Porta específica**      | `tcp.port == 443` ou `udp.port == 53` |
| **Procurar erros de requisição HTTP** | `http.response.code >= 400`           |
| **Identificar Handshakes TCP**        | `tcp.flags.syn == 1`                  |

---

## ☁️ Aplicação Prática em Cloud Security

- **Investigação de Incidentes (DFIR):** Análise de arquivos `.pcap` exportados para identificar tráfego malicioso, exfiltração de dados ou varreduras de rede (_port scanning_).
- **Validação de Criptografia:** Verificação prática se o tráfego sensível realmente está usando **TLS 1.2/1.3** ou se há dados trafegando em texto claro (_plain text_ como `HTTP`, `FTP`, `Telnet`).
- **Troubleshooting de Conectividade:** Identificação de bloqueios de firewall, falhas de handshake TCP, retransmissões de pacotes e problemas de resolução de DNS em instâncias na nuvem.
- **VPC Traffic Mirroring:** Análise de espelhamento de tráfego de redes privadas (ex: AWS VPC Traffic Mirroring) enviando cópias de pacotes para uma instância de monitoramento com Wireshark/TShark.
