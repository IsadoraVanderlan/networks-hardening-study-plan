# curl – Análise e Transferência HTTP/HTTPS

💡 Analogia do Dia a Dia

O curl é como um Navegador Web via Linha de Comando (sem interface gráfica). Enquanto o Chrome ou Firefox renderizam botões, imagens e layout bonitinho, o curl conversa diretamente com a "cozinha" do site, permitindo enviar e receber dados brutos, inspecionar cabeçalhos de resposta e testar APIs de forma transparente.

## 🛠️ Para que serve?

Transferir dados de/para servidores usando diversos protocolos (com foco em HTTP/HTTPS). É indispensável para testar APIs REST, verificar códigos de status (200 OK, 404 Not Found, 500 Internal Error) e analisar requisições/respostas HTTP.

## 📌 Principais Parâmetros

-I / --head: Traz apenas os cabeçalhos HTTP (Headers), sem baixar o corpo da página.

-v / --verbose: Modo detalhado. Mostra toda a conversa entre o cliente e o servidor (handshake, requisição enviada, cabeçalhos recebidos).

-X: Define o método HTTP (ex: GET, POST, PUT, DELETE).

-d / --data: Envia dados no corpo da requisição (usado em POST/PUT).

-H: Adiciona um cabeçalho customizado à requisição (ex: tokens de autorização).

-k / --insecure: Permite conexões HTTPS "inseguras" ignorando erros de certificados SSL/TLS inválidos ou autoassinados.

-L / --location: Sabe e segue redirecionamentos HTTP (código 301/302).

## 💻 Exemplos Práticos

# Inspecionar apenas o cabeçalho de um site
curl -I https://exemplo.com

# Fazer uma requisição visualizando todo o handshake e cabeçalhos
curl -v https://exemplo.com

# Enviar dados via POST para uma API com cabeçalho JSON
curl -X POST https://api.exemplo.com/login \
  -H "Content-Type: application/json" \
  -d '{"usuario":"admin", "senha":"123"}'

# Baixar um arquivo seguindo redirecionamentos
curl -L -O https://exemplo.com/arquivo.zip


💡 Dica Criativa: Precisa descobrir rapidamente se uma página está redirecionando corretamente? Use curl -I -L https://seu-site.com e veja todos os saltos de URL e códigos de status de uma vez só!
