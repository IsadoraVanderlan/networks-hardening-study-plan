# ⚖️ Load Balancer — Camada 4 (L4) vs. Camada 7 (L7)

> **Definição Simples:** O **Load Balancer** (Balanceador de Carga) distribui o tráfego da rede entre múltiplos servidores para garantir alta disponibilidade e evitar sobrecarga. A diferença entre L4 e L7 está em **qual camada do modelo OSI** ele analisa para tomar as decisões de roteamento.

---

## 🆚 Comparativo: L4 vs. L7

| Característica       | Load Balancer L4 (Camada de Transporte)                     | Load Balancer L7 (Camada de Aplicação)                                        |
| :------------------- | :---------------------------------------------------------- | :---------------------------------------------------------------------------- |
| **Foco**             | Protocolos `TCP` / `UDP` e Endereços IP/Portas              | Conteúdo da requisição (`HTTP`, `HTTPS`, `Headers`, `Cookies`, `URL`)         |
| **Visão do Tráfego** | Não lê o conteúdo das mensagens (cego para dados do pacote) | Lê e inspeciona o payload completo da requisição                              |
| **Performance**      | **Extremamente rápido** e com menor consumo de CPU          | Requer mais processamento por inspecionar o conteúdo                          |
| **Roteamento**       | Baseado apenas em IP de origem/destino e Porta              | Roteamento avançado baseado em caminhos (`/api`, `/blog`), headers ou cookies |
| **Terminação TLS**   | Pass-through rápido (ou terminação TCP simplificada)        | Realiza **TLS Termination** nativo e completo                                 |

---

## 🛠️ Casos de Uso na Nuvem

### 🔹 Layer 4 (Network Load Balancer - NLB)

- **Aplicações de Altíssimo Desempenho:** Jogos online, banco de dados, fluxos de vídeo ao vivo.
- **Tráfego Não-HTTP:** Comunicação via conexões TCP/UDP genéricas, gRPC, VPNs ou SMTP.
- **Volume Extremo:** Capaz de lidar com milhões de requisições por segundo com baixíssima latência.

### 🔸 Layer 7 (Application Load Balancer - ALB)

- **Aplicações Web e Microserviços:** Redirecionamento de tráfego por rota (ex: `site.com/api` vai para o Cluster A; `site.com/images` vai para o S3/Cluster B).
- **Sessões Pegajosas (_Sticky Sessions_):** Direciona o mesmo usuário para o mesmo servidor usando cookies HTTP.
- **Integração com WAF:** Facilita o bloqueio de ameaças de aplicação (SQLi, XSS) diretamente na borda.

---

## ☁️ Aplicação Prática em Cloud Security

- **AWS ALB vs. AWS NLB:** O ALB é ideal para APIs REST e sites HTTPS com inspeção WAF; o NLB é usado para alta performance em redes internas/bancos de dados.
- **Segurança Perimetral:** Tanto L4 quanto L7 atuam como ponto de entrada controlado, evitando expor os servidores backend diretamente à Internet.
- **Proteção contra DDoS:** O L4 mitiga ataques volumétricos (SYN Flood), enquanto o L7 mitiga ataques focados na camada de aplicação (HTTP Floods).
