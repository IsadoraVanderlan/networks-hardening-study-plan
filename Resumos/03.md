# Resumo de Aula: Encapsulamento e Desencapsulamento

## 1. Introdução

O **encapsulamento** e o **desencapsulamento** são os processos fundamentais que permitem a trafegabilidade e a organização da informação em uma rede de computadores. À medida que um dado viaja através das camadas do modelo de rede (da Aplicação até o meio físico e vice-versa), cada camada adiciona ou remove informações de controle específicas (cabeçalhos e rodapés) para garantir a entrega correta e confiável.

- **Importância Prática:** Compreender esse fluxo é essencial para a análise de tráfego com ferramentas como Wireshark, diagnóstico de problemas de conectividade (troubleshooting) e configuração de regras de segurança em firewalls e roteadores.

---

## 2. O Processo de Encapsulamento (Origem -> Envio)

No dispositivo de origem (remetente), os dados descem pelas camadas, sendo empacotados sucessivamente:

- **1. Camada de Aplicação (L7):**
  - O usuário gera a informação (ex: uma requisição HTTP ou mensagem).
  - **PDU (Unidade de Dados):** Dados / Mensagem.

- **2. Camada de Transporte (L4):**
  - Adiciona o cabeçalho L4 contendo as **portas de origem e destino** (ex: porta 80/443 para Web, porta 22 para SSH) e dados de controle de fluxo.
  - **PDU:** **Segmento** (se usar TCP) ou **Datagrama** (se usar UDP).

- **3. Camada de Rede (L3):**
  - Anexa o cabeçalho L3 contendo o **endereço IP de origem e IP de destino**.
  - **PDU:** **Pacote** (_Packet_).

- **4. Camada de Enlace (L2):**
  - Adiciona o cabeçalho L2 contendo o **endereço MAC de origem e MAC de destino**, além de um rodapé (_FCS/Trailer_) para verificação de erros.
  - **PDU:** **Quadro** (_Frame_).

- **5. Camada Física (L1):**
  - Converte o quadro em sinais elétricos, ópticos ou de rádio para transmissão pelo meio físico.
  - **PDU:** **Bits** (0s e 1s).

---

## 3. O Processo de Desencapsulamento (Destino -> Recebimento)

No dispositivo de destino (receptor), o processo ocorre na ordem inversa, "desembalando" a informação de baixo para cima:

1. **Camada Física (L1):** Recebe os sinais físicos do meio e os converte de volta em **bits**.
2. **Camada de Enlace (L2):** Lê o cabeçalho L2, valida o **endereço MAC de destino** e a integridade do quadro, remove o cabeçalho/rodapé L2 e envia o conteúdo para a camada superior.
3. **Camada de Rede (L3):** Processa o cabeçalho L3, confirma se o **endereço IP de destino** pertence ao host (ou se precisa rotear), remove o cabeçalho IP e repassa ao transporte.
4. **Camada de Transporte (L4):** Inspeciona a **porta lógica de destino** no cabeçalho L4 para entregar os dados ao processo/aplicação correto na máquina, removendo o cabeçalho L4.
5. **Camada de Aplicação (L7):** Recebe os **dados puros** e os exibe para a aplicação do usuário.

## 4. Analogia do Envio de uma Carta Comercial

Para fixar o conceito de empacotamento em camadas:

1. **A Mensagem (L7 - Aplicação):** Você escreve o texto da carta com o conteúdo principal.
2. **Caixa/Proteção Interna (L4 - Transporte):** Você coloca a carta dentro de uma pasta e identifica a qual **departamento** interno ela se destina.
3. **Envelope com Endereço (L3 - Rede):** Coloca a pasta dentro de um envelope dos Correios e escreve o **CEP e endereço IP** de destino.
4. **Etiqueta da Agência e Lote (L2 - Enlace):** A agência do correio cola um selo/código de barras físico com o **RG/MAC do entregador local** que vai transportar o pacote até o próximo ponto.
5. **O Caminho Físico (L1 - Física):** O caminhão transporta o envelope pelas rodovias (sinais/bits). Na chegada, o destinatário abre o envelope camada por camada até ler a mensagem.
