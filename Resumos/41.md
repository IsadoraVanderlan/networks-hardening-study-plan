## 📌 Solução de Problemas de Firewall

### 🎯 Objetivo
Diferenciar se uma porta de aplicação está de fato fechada no servidor ou se o tráfego está sendo silenciosamente descartado (*dropped*) por um firewall.

### 🛠️ Ferramentas & Comandos Vitais

| Comando | Sintaxe de Exemplo | Finalidade no Troubleshooting | Cenário Real no Dia a Dia de Cloud Security |
| :--- | :--- | :--- | :--- |
| **`ufw`** *(Ubuntu/Debian)*<br>Firewall Simplificado de Host | `sudo ufw status verbose` | Verificação de **status das regras ativas** e portas liberadas no sistema operacional local. | **Validação Rápida de Acesso:** Checar se a porta de uma aplicação (`80/443/22`) está sendo bloqueada pelo próprio servidor antes de checar a nuvem. |
| **`iptables` / `nftables`** *(Linux)*<br>Filtragem Avançada de Pacotes | `sudo iptables -L -n -v` | Inspeção detalhada de **tabelas de regras (*INPUT/OUTPUT/FORWARD*)** e contadores de pacotes descartados. | **Diagnóstico de Regras Conflitantes:** Identificar se uma regra genérica de *DROP* está sobrepondo a liberação de um tráfego específico. |
| **`nc` (netcat) / `telnet`**<br>Teste de Alcance de Porta TCP/UDP | `nc -zvw3 192.168.10.1 443` | Validação pontual de **conectividade de porta em camada 4** sem depender da resposta do ICMP/ping. | **Teste de Liberação de Firewall:** Confirmar se uma Security Group/Firewall liberou o acesso à porta TCP do banco de dados ou aplicação. |
| **`tail` / `grep`** *(Logs de Firewall)*<br>Inspeção de Logs de Eventos | `sudo tail -f /var/log/ufw.log` | Monitoramento em tempo real de **pacotes bloqueados e rejeitados** pela interface de rede. | **Rastreio de Bloqueio em Tempo Real:** Identificar a IP de origem exata e a porta que está sofrendo bloqueio ao tentar conexão. |

### ☁️ Visão Cloud & Cyber Security
* **Stateful vs. Stateless:**
  * **Security Groups (Stateful):** Ao liberar a entrada na porta 443, a resposta de saída é permitida automaticamente.
  * **Network ACLs / NACLs (Stateless):** Exigem regras explícitas de **Entrada** e **Saída** (prestando atenção às portas efêmeras `1024-65535`).
* **WAF (Web Application Firewall):** Bloqueios na camada 7 que inspecionam o conteúdo da requisição HTTP (ex: SQLi, XSS).
