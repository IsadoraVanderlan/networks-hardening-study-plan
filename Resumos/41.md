## 📌 Solução de Problemas de Firewall

### 🎯 Objetivo
Diferenciar se uma porta de aplicação está de fato fechada no servidor ou se o tráfego está sendo silenciosamente descartado (*dropped*) por um firewall.

### 🛠️ Ferramentas & Comandos Vitais

| Comando | Parâmetros / Exemplo | Finalidade no Troubleshooting |
| :--- | :--- | :--- |
| `netcat` (`nc`) | `nc -zv 192.168.1.1 443` | Teste rápido de conectividade em porta TCP/UDP específica. |
| `Test-NetConnection` (PowerShell) | `Test-NetConnection 1.1.1.1 -Port 80` | Ferramenta nativa do Windows para validar rotas e portas TCP. |
| `nmap` | `nmap -p 22,80,443 <IP>` | Mapeamento detalhado do estado da porta (*open*, *closed*, *filtered*). |
| `telnet` | `telnet <IP> <Porta>` | Método legado para teste de abertura de socket TCP. |

### 🧪 Laboratório Prático & Troubleshooting

#### **1. Validação de Porta Aberta vs. Porta Bloqueada**
```bash
# Teste de porta HTTPS (Aberta)
nc -zv google.com 443

# Teste de conexão em PowerShell
Test-NetConnection google.com -Port 443
```
![Teste de Porta com Netcat](assets/aula41-firewall.png)

* **Análise dos Resultados:**
  * **Connection succeeded / succeeded: true:** Indica que a regra de firewall permite a passagem e a porta está escutando.
  * **Connection timed out:** Tipicamente indica bloqueio por Firewall/Security Group (*filtered*).

### ☁️ Visão Cloud & Cyber Security
* **Stateful vs. Stateless:**
  * **Security Groups (Stateful):** Ao liberar a entrada na porta 443, a resposta de saída é permitida automaticamente.
  * **Network ACLs / NACLs (Stateless):** Exigem regras explícitas de **Entrada** e **Saída** (prestando atenção às portas efêmeras `1024-65535`).
* **WAF (Web Application Firewall):** Bloqueios na camada 7 que inspecionam o conteúdo da requisição HTTP (ex: SQLi, XSS).
