# 💻 tcpdump — Análise de Tráfego em Linha de Comando

> **Definição Simples:** O **`tcpdump`** é o analisador de pacotes de rede via linha de comando (CLI) mais utilizado em sistemas Linux. Ele é a versão "mão na massa" e sem interface gráfica do Wireshark, essencial para inspecionar tráfego diretamente em servidores e instâncias Cloud sem ambiente de desktop.

---

## 🛠️ Comandos Mais Usados no Dia a Dia

- **Capturar pacotes em uma interface específica:**
  ```bash
  sudo tcpdump -i eth0
  ```
- **Limitar a quantidade de pacotes capturados:**
  ```bash
  sudo tcpdump -i eth0 -c 10
  ```
- **Filtrar por Endereço IP (origem ou destino):**
  ```bash
  sudo tcpdump -i eth0 host 192.168.1.50
  ```
- **Filtrar por Porta Específica (ex: HTTPS / TLS):**
  ```bash
  sudo tcpdump -i eth0 port 443
  ```
- **Exibir conteúdo em formato ASCII e Hexadecimal (ver payload):**
  ```bash
  sudo tcpdump -i eth0 -A port 80
  ```
- **Salvar captura em um arquivo `.pcap` (para abrir no Wireshark depois):**
  ```bash
  sudo tcpdump -i eth0 -w captura.pcap
  ```
- **Ler um arquivo `.pcap` salvo:**
  ```bash
  sudo tcpdump -r captura.pcap
  ```

---

## 🎯 Combinação de Filtros Complexos (Sintaxe BPF)

O `tcpdump` permite usar operadores lógicos (`and`, `or`, `not`) para refinamento:

```bash
# Capturar tráfego HTTP vindo do IP 10.0.0.5 ignorando conexões SSH (porta 22)
sudo tcpdump -i eth0 'src 10.0.0.5 and port 80 and not port 22'
```

## ☁️ Aplicação Prática em Cloud Security

- **Troubleshooting em Instâncias Sem Interface Gráfica:** Inspeção rápida em instâncias **AWS EC2**, **GCP Compute Engine** ou containers Linux via terminal SSH.
- **Coleta para Forense Digital (DFIR):** Geração agilizada de arquivos `.pcap` no servidor afetado para posterior análise detalhada no Wireshark.
- **Validação de Regras de Firewall e Security Groups:** Verificação em tempo real se os pacotes chegam à placa de rede da máquina virtual ou se estão sendo descartados no perímetro.
- **Auditoria de Tráfego Em Claro:** Identificação de conexões inseguras sem criptografia (como requisições `HTTP` ou conexões `Telnet`/`FTP`) rodando em redes privadas.
