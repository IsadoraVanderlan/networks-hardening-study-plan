# 📝 Roteamento e Segurança de Redes

**Objetivo da Aula:** Compreender como o tráfego é direcionado na rede e como utilizamos as tabelas de rotas para proteger infraestruturas na nuvem e _on-premises_.

---

### **1. O que é Roteamento?**

É o processo de escolher o **melhor caminho** para que os pacotes de dados saiam da origem e cheguem ao destino correto.

- **Analogia Prática:** A internet é como um país. Os pacotes de dados são as cartas, os roteadores são as agências dos correios, e o roteamento é o trabalho de descobrir qual estrada usar para entregar a carta mais rápido.
- **Hop-by-Hop (Salto por Salto):** Seu computador não precisa conhecer o caminho inteiro até o destino. Ele só precisa entregar para o próximo "posto de controle" (o roteador local), que passa para o provedor, e assim por diante.
- **Comando Prático:** Use `tracert 8.8.8.8` no Prompt de Comando (CMD) do Windows para visualizar todos os saltos que seu pacote dá até chegar no servidor do Google.

---

### **2. A Tabela de Roteamento (O "Mapa")**

É a lista de regras mantida pelo sistema operacional (ou pelo roteador) que define para onde enviar cada pacote de dados. No Windows, a visualização é feita através do comando **`route print`**.

- **`0.0.0.0` (Gateway Padrão):** Representa a saída para a Internet. Quando a máquina precisa se comunicar com um IP desconhecido ou externo, ela joga o pacote para essa rota.
- **`127.0.0.1` (Loopback):** Endereço reservado para a máquina se comunicar internamente com ela mesma (testes e serviços locais).
- **Custo (Métrica):** Representa o "esforço" da viagem. O sistema **sempre escolhe a rota com o menor custo**. Por exemplo, um cabo de rede costuma ter custo menor do que o Wi-Fi. Caso a conexão de menor custo falhe, o sistema assume a rota secundária de maior custo (redundância/failover).

---

### **3. A Escala da Internet: IP vs. AS**

A internet não é uma rede única, mas sim uma interconexão de redes menores.

- **IP (Endereço):** Identifica um dispositivo individual dentro de uma rede (ex: seu computador ou servidor).
- **Sub-rede:** Representa um bloco ou segmento da rede (um grupo de IPs).
- **AS (Sistema Autônomo):** É uma infraestrutura de rede gigante gerenciada por uma única organização com políticas próprias de roteamento. Exemplos: AS da AWS, AS do Google, AS da Vivo, AS da Claro.

---

### **4. Conceitos Fundamentais (Visão para Cloud Security Junior)**

Não é necessário configurar esses protocolos do zero no nível Júnior, mas é essencial reconhecer os papéis de cada conceito:

- **RIB vs. FIB:**
  - **RIB (_Routing Information Base_):** O rascunho completo contendo **todas** as rotas possíveis conhecidas.
  - **FIB (_Forwarding Information Base_):** O GPS ativo contendo apenas a **melhor rota** selecionada para acelerar o encaminhamento dos pacotes.
- **IGP (OSPF e IS-IS):** Protocolos de roteamento **interno**. Atuam como o mapa interno da empresa ou data center, onde todos os roteadores pertencem à mesma organização e confiam entre si.
- **EGP (BGP):** Protocolo de roteamento **externo**. Conecta diferentes Sistemas Autônomos (AS) na internet (ex: faz a ponte entre a nuvem da AWS e a rede corporativa).

---

### 🔐 **Aplicações em Cloud Security**

No dia a dia de segurança em nuvem, o roteamento atua como a **primeira linha de defesa**:

- **Isolamento de VPC:** Garantir que recursos sensíveis (como bancos de dados) fiquem em **Sub-redes Privadas**, ou seja, sem a rota `0.0.0.0/0` apontando diretamente para um _Internet Gateway_ (IGW).
- **Auditoria de Integridade:** Inspecionar tabelas de rotas locais para identificar se trocas indevidas de gateway aconteceram por malwares ou conexões não autorizadas (_Traffic Hijacking_).
- **Mitigação de Ataques DoS/DDoS:** Compreender o caminho dos pacotes para implementar controles de filtragem (como AWS WAF ou firewalls corporativos) antes que o tráfego volumoso e malicioso atinja os servidores internos.
